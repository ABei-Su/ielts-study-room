# 独立版部署

独立版使用普通账号密码，手机和电脑连接同一 HTTPS 地址后读取相同的服务器记录。无需 ChatGPT 登录。站点尚未部署：需要可使用的云服务器、域名和 HTTPS。当前 chatgpt.site 站点不变。官方原题和录音仍引用 IELTS.org，是否能加载需在使用网络上验证；网页本身可访问不代表海外题面一定可访问。

## 快速部署（服务器）

前提：Node 24.15+ 或 Docker；域名已指向服务器；HTTPS 反向代理保留原始 Host 并转发至 127.0.0.1:8080。域名和云主机开通由账号持有人操作。

1. 在服务器的私密环境设置中配置 `APP_ORIGIN=https://你的域名`（无尾部斜杠）、`STUDY_USERNAME`（3–40 位字母/数字/点/下划线/短横线）、`STUDY_INITIAL_PASSWORD`（12–200 字符）。不要把真实配置写入仓库或聊天。
2. 在项目目录运行 `docker compose up -d --build`。使用命名卷 `study-data` 持久保存记录。外网只放行反向代理的 HTTPS 端口，8080 仅监听本机。
3. 首次启动创建唯一账号，不开放注册。首次启动成功后移除 `STUDY_INITIAL_PASSWORD`，已有账号仍可使用。再次设置该变量不会覆盖已有密码。
4. 访问域名登录，分别用手机和电脑保存及读取一条测试草稿，并测试刷新、退出、再次登录。

无 Docker：`npm ci`、`npm run build:independent`，设置上述环境变量及 `DATA_DIR`（持久可写目录），执行 `npm run start:independent`，用主机进程管理器守护。正式部署要求 HTTPS；仅本机开发允许 `APP_ORIGIN=http://localhost:8080`。

## 保存、备份与恢复

SQLite 数据包含账号哈希、会话、草稿、生词与复习记录。账号密码不以明文保存。默认会话 1 天，勾选保持登录为 30 天。错误登录 8 次后限制 15 分钟；重启不会清空限制。只运行一个实例，共用一个本地持久卷；不能将临时磁盘或多个副本当成跨设备存储。

定期停服务后备份完整数据卷（含 SQLite 及其 WAL/SHM 文件），备份中也含私密学习资料。恢复时停服务，将完整备份还原后启动。网页“学习记录”另有 JSON 导出功能；目前没有旧站点自动迁移/网页导入。旧 D1 数据不会被删除。部署前若旧站有学习记录，应先导出并单独验证迁移。

本版没有自助忘记密码；部署管理员需要通过受控维护过程重置账号并撤销会话。不要删除数据卷来重置密码。

## 验证

`npm run verify`：格式、8 组测试（其中一组包含登录/持久化集成断言）、类型、lint、独立构建、旧 Sites 构建。独立集成测试仅创建临时 SQLite，不连接线上账号。

Docker 镜像构建及目标云服务器部署仍需在具备 Docker/服务器权限的环境验证。国内访问能力需要目标网络实测，不能由本地构建结果保证。
